# 非機能要件

プロジェクトで検証可能な非機能要件を管理する。

- `security.md`: 認証、認可、暗号化、コンプライアンス
- `performance.md`: レスポンスタイム、スループット、スケーリング
- `cost.md`: 予算、タグ付け、FinOps
- `reliability.md`: 可用性、RTO/RPO、バックアップ、フェイルオーバー
- `operational-excellence.md`: ロギング、監視、デプロイ、オンコール

各文書には、測定可能な目標、制約、検証方法を記載する。実装手順や障害対応手順は `operations/` に分ける。
